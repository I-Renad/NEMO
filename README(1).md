# NEMO — The Ocean Remembers

**AI Through My Eyes | HUMAN.exe**

NEMO is an interactive, bilingual (Arabic/English) browser experience about an imaginary ocean research robot. The visitor explores coral reef zones, scans simulated environmental observations, reviews AI-style assessments, and makes human decisions about the evidence.

> AI can discover patterns. Humans decide what they mean.

## My perspective | وجهة نظري

أرى الذكاء الاصطناعي أداة توسّع فضول الإنسان وقدرته على الاكتشاف. يستطيع مساعدتنا في ملاحظة الأنماط وتحليل المعلومات واقتراح الاحتمالات، لكن نتائجه تحتاج إلى تحقق وتفسير ومسؤولية بشرية. لذلك صممت NEMO ليكون الذكاء الاصطناعي فيه مساعدًا للباحث، لا بديلًا عنه.

## How to play | طريقة اللعب

1. Open the game and start the mission.
2. Explore the underwater scene using the controls shown in the game.
3. Scan coral reef zones and review simulated observations.
4. Choose how to respond to NEMO's assessment.
5. Review the mission report and educational sections.

The data and assessments are **fictional educational simulations**, not real measurements or outputs from a live machine-learning model.

## AI Through My Eyes — Required elements

1. **AI in My Words:** The creator's perspective on AI as a tool for discovery that requires human judgment.
2. **AI Around Us:** Three real-world application examples described within the experience.
3. **What Surprised Me:** The importance of uncertainty and the difference between confident output and verified knowledge.
4. **How AI Helped Me:** A section about AI-assisted brainstorming, design, and coding, and the human decisions shaping the project. Review this section to ensure it matches the actual development process.

The site also includes a sources/credits section.

## Run locally

Open `index.html` in a modern browser. If local file previews block JavaScript, publish it through GitHub Pages and open the public URL.

## Publish on GitHub Pages

1. Create a public GitHub repository named `NEMO`.
2. Upload `index.html` and `README.md` to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, branch `main`, folder `/(root)`, and save.
5. Wait for the published URL and test the controls on mobile and desktop.

## Important

This is a self-contained HTML build with embedded styling, scripts, and visual assets. No API key or backend is required. The project does **not** claim to perform actual ocean monitoring. The educational content and attribution should be reviewed by the creator before final submission.
