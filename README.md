# NEMO — The Ocean Remembers

**AI Through My Eyes | HUMAN.exe**

NEMO is an interactive, bilingual (Arabic/English) browser experience about an imaginary ocean research robot. The visitor explores coral reef zones, scans simulated environmental observations, reviews AI-style assessments, and makes human decisions about the evidence.

> AI can discover patterns. Humans decide what they mean.

## My perspective | وجهة نظري

أرى الذكاء الاصطناعي أداة توسّع فضول الإنسان وقدرته على الاكتشاف. يستطيع مساعدتنا في ملاحظة الأنماط وتحليل المعلومات واقتراح الاحتمالات، لكن نتائجه تحتاج إلى تحقق وتفسير ومسؤولية بشرية. لذلك صممت NEMO ليكون الذكاء الاصطناعي فيه مساعدًا للباحث، لا بديلًا عنه.

## How to play | طريقة اللعب

1. Open the game and start the mission.
2. Explore the underwater scene using the controls shown in the game.
3. Scan coral reef zones and review simulated observations.
4. Choose how to respond to NEMO's assessment.
5. Review the mission report and educational sections.

The data and assessments are **fictional educational simulations**, not real measurements or outputs from a live machine-learning model.


## Important

This is a self-contained HTML build with embedded styling, scripts, and visual assets. No API key or backend is required. The project does **not** claim to perform actual ocean monitoring.
